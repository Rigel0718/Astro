Python을 공부하다 보면 자주 듣게 되는 말이 있다.

> Everything in Python is an object.

Python에서는 정수도 객체, 문자열도 객체, 함수와 클래스마저도 객체다.

**그럼 객체가 뭐길래 Python에서는 모든 것을 객체라고 하는 걸까?**

Python의 객체를 제대로 이해하려면 `class` 문법부터 시작하기보다, 'Python이라는 언어가 데이터를 어떤 방식으로 바라보는가'부터 이해할 필요가 있다.

---
## 1. Python 객체란 무엇인가?

객체(Object)라는 말을 파이썬으로 처음 배우면 보통 `class`와 함께 접하게 된다.

```python
class Person:
	pass
	
person = Person()
```

이때 우리는 흔히 `person`을 `Person` 클래스의 객체라고 배운다.

틀린 설명은 아니지만 Python에서 객체의 의미는 이것보다 훨씬 넓다.

```python
10
"hello"
[1,2,3]
```

이것들도 모두 객체다.

심지어 함수도, 클래스도 객체다.

```python
def hello():
	print("Hello")
	

class Person:
	pass
```

즉 Python에서 객체는 단순히 "**class를 이용해서 직접 생성한 인스턴스**"만을 의미하지 않는다.
Python에서 프로그램이 실행되는 동안 존재하고 다루어지는 거의 모든 값을 객체로 표현한다.
그렇다면, Python에서 말하는 객체를 조금 더 정확하게 정의해볼 필요가 있다.

### Python 객체의 특성
Python 객체는 세 가지 중요한 특성을 가진다.

- **Identity**
- **Type**
- **Value**

예를 들어 다음 리시트가 있다고 해보자.

`numbers = [1, 2, 3]`

우리는 이 객체에 대해 다음과 같은 질문을 할 수 있다.

```python
id(numbers)
type(numbers)
numbers
```

`id()`는 이 객체를 다른 객체와 구별할 수 있는 **identity**를 보여준다.

`type()`은 이 객체가 어떤 **type**을 가지는지 보여준다.

그리고 `[1,2,3]`이라는 현재 내용은 객체의 **value**와 관련되어 있다.

따라서 Python 객체를 처음 이해할 때는 다음과 같이 생각해볼 수 있다.

> Python 객체는 고유한  identity를 가지며, 특정 type에 속하고, 어떤 value를 가지는 존재다.

이 세 가지는 앞으로 Python의 객체 모델을 이해하는 중요한 기준이 된다.

---
## 2. Python에서 변수는 값을 담는 상자가 아니다.

객체를 이해하면 우리가 흔히 사용하는 _변수_ 도 조금 다르게 보이기 시작한다.
다음 코드를 생각해보자.

```python
a = 10
```
프로그래밍을 처음 배울 때는 이것을 보통 다음과 같이 이해한다.

> `a`라는 변수 공간에 `10`이라는 값을 저장했다.

입문 단계에서는 충분히 유용한 설명이지만 Python 객체 모델을 이해하기에는 부족하다.

Python에서는 `10`이라는 정수 객체가 존재하고, `a`라는 이름이 그 객체를 가리킨다고 이해하는 것이 적절하다.
```
a ─────→ 10 
         ↑ 
       object
```

이 차이는 처음엔 별것 아닌 것처럼 보인다.

하지만 다음 코드를 보면 중요해 진다.

```python
a = [1,2,3]
b = a
```

이것을 단순히 "변수에 값이 들어간다"라고 생각하면 `a`와 `b`안에 각각 리스트가 하나씩 들어 있다고 오해하기 쉽다.

Python 객체 관점에서는 아래와 같이 생각할  수 있다.

```
Name                 Object
 a ─────┐
        ├──────────→ [1, 2, 3]
 b ─────┘
```

`a`와 `b`라는 두 이름이 **같은 객체를 가리킬 수도 있는 것이다.**

그래서 Python을 깊게 이해하려면 변수보다 먼저 **객체와 객체를 가리키는 이름의 관계**를 이해해야 한다.

다만 이 관계는 다음 글에서 더 자세히 다룰 예정이다.

지금은 한 가지만 기억하면 충분하다.

> **Python의 중심에는 변수가 아니라 객체가 있고, 이름은 그 객체를 가리킨다.**

## 3. 왜 Python은 이렇게 설계되었는가?

그렇다면 왜 Python은 숫자나 문자열뿐만 아니라 함수와 클래스까지 객체로 다룰까?

이를 이해하려면 먼저 **객체지향 언어라는 것과 모든 것을 객체로 다룬다는 것을 구분할 필요가 있다.**

Java나 C++ 역시 대표적인 객체지향 언어다.

이들 언어에서도 클래스를 정의하고 객체를 생성하며, 캡슐화, 상속, 다형성과 같은 객체지향적인 설계를 사용할 수 있다.

하지만 **객체지향 프로그래밍을 지원한다는 것이 언어의 모든 구성 요소가 객체라는 뜻은 아니다.**

예를 들어 Java에는 객체와 별도로 primitive type이 존재한다.

```
int number = 10;
boolean active = true;
```

`int`, `boolean`과 같은 값들은 일반적인 Java 객체와 동일한 방식으로 표현되는 것이 아니다.

C++ 역시 객체뿐만 아니라 primitive value, pointer, function 등 서로 다른 종류의 언어 요소를 가지고 있다.

즉 객체지향 언어라고 하더라도 언어 안의 모든 것이 반드시 하나의 객체 모델로 통일되어 있을 필요는 없다.

Python은 이 부분에서 조금 다른 선택을 했다.

Python에서는 정수도 객체다.

```python
number = 10
print(type(number))

# 결과
<<class 'int'>>
```
문자열과 리스트도 객체다.
```python
type("hello)
type([1,2,3])
```

Python은 **함수와 클래스처럼 프로그램 자체를 구성하는 요소들까지 실행 중에 다룰 수 있는 객체로 표현한다.**

```python
def hello():
	print("Hello")
```

함수를 정의하면 `hello`는 단순히 함수의 이름이라는 특별한 문법으로만 존재하는 것이 아니다.
실행 중에는 하나의 함수 객체가 존재하고 `hello`라는 이름이 그 객체를 가리킨다.

```
hello ─────→ [ function object ]
```

따라서 함수도 다른 객체와 마찬가지로 새로운 이름에 할당할 수 있다.
```python
func = hello
```

다른 함수에 전달할 수도 있다.
```python
def execute(func):
	func()
	
execute(hello)
```

자료구조 안에 넣을 수도 있다.
```python
functions = [hello]
```

함수를 반환하는 것도 가능하다.
```python
def get_function():
	return hello
```

이처럼 함수를 다른 값처럼 전달하고 저장하고 반환할 수 있는 성질을 **일급 함수(first-class function)** 라고 한다.

여기서 한 가지 주의할 점이 있다.

**함수를 값처럼 다룰 수 있다는 것 자체가 Python만의 특징은 아니다**

JavaScript에서도 함수는 일급 값으로 다뤄지며, C++에서도 함수 포인터나 lambda, `std::function` 등을 이용해 함수를 전달할 수 있다. 현대 Java 역시 lambda와 functional interface를 통해 동작을 전달할 수 있다.

따라서 Python의 특징을 단순히 "Python에서는 함수도 전달할 수 있다."라고 이해하는 것은 정확하지 않다.

더 중요한 특징은 **Python이 다양한 실행 요소들이 상당히 일관된 객체 모델 위에서 다룬다는 점** 이다.

```python
class User:
    pass

MyClass = User

user = MyClass()
```

`User`라는 클래스 자체가 객체이기 때문에 다른 이름에 할당하거나, 함수에 전달하거나, 자료구조에 저장할 수 있다.

이러한 객체 모델은 Python의 동적인 특성과도 깊게 연결되어 있다.

실행 중에 함수를 선택하거나 교체할 수 있고, 클래스를 전달할 수 있으며, 객체의 타입과 attribute를 조사하고 조작할 수도 있다.

 따라서 Python에서 객체는 단순히 객체지향 프로그래밍을 위한 기능 하나가 아니다.
**Python이라는 언어가 실행 중의 값과 프로그램 구성 요소를 표현하고 다루는 기본적인 모델에 가깝다.**
그리고 바로 이 점에서 Python에서 자주 등장하는 표현이 나온다.

> Everything in Python is an object.

## 4. "Everything in Python is an Object"는 무슨 뜻인가?

이 말은 "Python에서는 모든 코드를 클래스로 작성해야 한다"는 의미가 아니다.
Python이 순수한 객체지향 스타일만을 강요한다는 의미도 아니다.
핵심은 **Python이 실행 중에 다루는 값들을 객체로 표현한다는 것** 이다.

```python
class User:
	pass
	
print(type(User))
```

`User`는 앞으로 객체를 만들어내기 위해 우리가 정의한 클래스다.

그런데 `User` 자체 역시 Python이 실행 중에 다룰 수 있는 하나의 객체다.

그래서 다음과 같은 코드도 가능하다.
```python
classes = [User]
SlectedClass = classes[0]
user = SelectedClass()
```

여기서 궁금증이 생긴다.

> 객체를 만들어내는 calss 자체도 객체라면, 그 class는 누가 만든 객체일까?

이 질문은 나중에 "Class 자체도 객체다"에서 다시 다룬다.
지금은 함수와 클래스조차 Python의 객체 모델 밖에 존재하는 특별한 존재가 아니라는 것만 기억하면 된다.

## 5. Python 객체를 바라보는 세 가지 축

앞에서 객체에는 세 가지 중요한 특성이 있다고 했다.

### Identity

Identity는 **이 객체가 바로 이 객체라는 것을 구별하는 정체성**이다.
두 객체가 같은 값을 가지고 있다고 해서 반드시 같은 객체인 것은 아니다.

```python
a = [1,2,3]
b = [1,2,3]

print(a == b)
print(a is b)
```

`a == b`는 `True`가 될 수 있다.
두 리스트 **값이 같기 때문**이다.

하지만 `a is b`는 `False`다.

두 리스트는 서로 별도로 만들어진 **다른 객체이기 때문**이다.

```
같은 값인가?     → ==
같은 객체인가?   → is
```
라는 차이가 생긴다.

이것이 객체의 **identity**를 이해해야 하는 이유다.

### Type

모든 객체는 자신의 타입을 가진다.

```
type(10)
type("hello")
type([1, 2, 3])
```

타입은 단순히 객체에 붙어 있는 이름표가 아니다.

**객체가 어떤 연산을 지원하고 어떻게 동작하는지와 깊게 연결**되어 있다.

예를 들어:
```
10 + 20
```
과
```
"hello" + " world"
```

는 같은 `+` 연산자를 사용하지만 서로 다른 방식으로 동작한다.

객체의 타입이 다르기 때문이다.

### Value

마지막 객체가  나타내는 **value**다.

```
a = [1, 2, 3]
```

이 리스트 객체는 `[1, 2, 3]`이라는 상태를 가지고 있다.

그리고 리스트는 변경 가능한 객체이므로 다음과 같이 상태가 바뀔 수도 있다.

```
a.append(4)
```

이제 객체의 내용은 다음과 같다.

```
[1, 2, 3, 4]
```

여기서 중요한 점은 **리스트의 내용이 바뀌었다고 해서 반드시 다른 객체가 된 것은 아니라는 것**이다.

같은 identity를 가진 객체의 value가 변경될 수 있다.
이 지점에서 Python의 **mutable / immutable** 개념도 연결되기 시작한다.
결국 Python 객체를 이해할 때 우리는 계속해서 세 가지 질문을 던질 수 있다.

```
이 객체는 누구인가?       → Identity
이 객체는 무엇인가?       → Type
이 객체가 나타내는 값은?   → Value
```

이 세 가지 축은 앞으로 메모리, 클래스, attribute, 상속 등을 이해할 때 계속 등장하게 된다.

## 6. 다음 글로 연결

지금까지 살펴본 내용을 한 문장으로 정리하면 다음과 같다.

> Python에서 객체는 특정 문법 기능이 아니라, 언어가 실행 중의 값과 프로그램 구성 요소를 표현하는 기본 단위다.

숫자도 객체다.

```
a = 10
```

문자열도 객체다.

```
name = "Python"
```

함수도 객체다.

```
def hello():
    pass
```

심지어 클래스 자체도 객체다.

```
class User:
    pass
```

그리고 각각의 객체는 **identity, type, value** 라는 특성을 가진다.

그런데 여기까지 이해하고 나면 오히려 새로운 의문이 생긴다.

우리는 지금까지 다음 코드를 너무 자연스럽게 사용해왔다.
```
a = 10
```

하지만 `10`이 객체라면 `a`는 무엇일까?

정말 `a`라는 메모리 공간 안에 `10`이 저장되어 있는 걸까?

그리고 다음과 같이 작성하면,

```
a = [1, 2, 3]
b = a
```

`a`와 `b`는 각각 별도의 값을 가지고 있는 것일까?

아니면 하나의 객체를 함께 가리키고 있는 것일까?

이 질문에 답하기 위해서는 Python의 **변수(variable)** 라는 개념을 다시 바라볼 필요가 있다.
